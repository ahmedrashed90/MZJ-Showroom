# MZJ Showroom Seasonal Design V58 CLEAN

نسخة Clean جديدة لطبقة عرض الشاشات، مع الحفاظ على منطق البيانات والـ APIs والـ Firestore وربط كل Screen ID بالسيارة الخاصة به.

## شاشة العرض
- طبقة العرض في `public/screen.html` + `public/screen.css` + `public/screen.js` مبنية من الصفر.
- لا تعتمد على طبقات تصميم V56/V57 أو CSS overrides قديمة.
- فريم صور السيارة تصميم فعلي داخل كل Theme، وليس مستطيلاً أبيض تقليدياً.
- الجزء الخاص بالبيانات والمواصفات Canvas بصري واحد، مع فواصل وعناصر مدمجة بدلاً من Cards منفصلة.
- المواصفات الداخلية والخارجية والأمان: 14 مواصفة في الصفحة، 7 يمين + 7 شمال.
- الصور والألوان والـ QR وقراءة السيارة والكاش وآلية التحديث محفوظة.

## التصميمات
- رمضان: كحلي + ذهبي، بدون مساجد أو مبانٍ دينية.
- اليوم الوطني: أخضر + ذهبي.
- يوم التأسيس: بني/ترابي.
- عيد الفطر: عاجي/ذهبي، بدون مساجد أو مبانٍ دينية.
- عيد الأضحى: عنابي/ذهبي، بدون مساجد أو مبانٍ دينية.

## هوية كل تصميم من الداش بورد
لكل تصميم إعدادات مستقلة في `showroom_theme_settings/{themeId}`:
- رفع/تغيير شعار المناسبة.
- التحكم في حجم الشعار.
- كتابة النص الذي يظهر تحت الشعار.
- اليوم الوطني يدعم أيضاً رقم اليوم الوطني، والافتراضي 96.

اختيار التصميم من الداش بورد يحدّث `showroom_settings/display.activeThemeId` ويطبّقه على كل الشاشات A1–A10.
