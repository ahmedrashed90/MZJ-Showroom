# MZJ Showroom Seasonal Design V65 CLEAN

نسخة كاملة من مشروع MZJ Showroom مع الحفاظ على منطق البيانات والربط والشاشات، وإعادة بناء منطقة التفاصيل والمواصفات في شاشة العرض بتكوين أكثر هدوءًا واحترافية.

## V65

- الحفاظ على مساحة الصور Safe Gallery بدون قص للصورة الأصلية.
- الحفاظ على شعارات المناسبات والنص واللون والإطار وحجم الخط من إعدادات الداش بورد.
- إعادة بناء منطقة البيانات بالكامل بإيقاع ثابت ومحاذاة واضحة بدل الـ orbit والعناصر المتحركة عشوائيًا.
- العنوان والسعر والألوان في Header واضح ومتماسك.
- المواصفات الرئيسية في Grid منظم بدون Cards مستقلة.
- المواصفات الفنية في شريط موحد مع Tabs بسيطة.
- الداخلية / الخارجية / الأمان في عمودين ثابتين 7 + 7 مع Pagination.
- إزالة الخطوط والمنحنيات التي كانت تمر داخل النصوص أو تسبب تداخل بصري.
- Tajawal هو الخط الأساسي.
- نفس Firestore / QR / image slider / screen assignment / theme logic بدون تغيير في منطق العمل.
