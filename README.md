# MZJ Showroom Seasonal Design V64 CLEAN

نسخة كاملة Clean مبنية على منطق V63 مع إعادة بناء أصلية لمنطقة البيانات والمواصفات في شاشة العرض.

## V64
- إزالة هيكل البلوكات/الجداول القديم من جهة البيانات.
- المواصفات الرئيسية أصبحت تكوينًا بصريًا مفتوحًا بنقاط معلومات على مسار زخرفي بدون Cards أو حدود لكل عنصر.
- المواصفات الفنية أصبحت شريطًا هندسيًا مفتوحًا مع تنقل بين المجموعات بدون صناديق بيانات.
- المواصفات الداخلية/الخارجية/الأمان تظهر في عمودين 7 + 7 بخطوط إرشادية وMarkers فقط، بدون صندوق كبير أو صفوف جدول.
- الحفاظ على Pagination لكل 14 عنصر.
- الحفاظ على منطق السيارات والصور والألوان وQR وFirestore واستقلال الشاشات.
- الحفاظ على Tajawal وإعدادات هوية المناسبات وألوان/Stroke النص.
- لا يوجد CSS patch أو override متراكم؛ تعريفات طبقة المعلومات استبدلت من المصدر نفسه.
