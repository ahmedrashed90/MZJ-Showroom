# MZJ Showroom Seasonal Design V59 CLEAN

نسخة Clean جديدة لطبقة عرض شاشات المعرض، مع الحفاظ على منطق البيانات والربط الموجود.

## ما تم بناؤه من جديد
- `public/screen.html` جديد بالكامل لصفحة العرض.
- `public/screen.css` جديد بالكامل بدون CSS Overrides أو Patch فوق طبقة التصميم السابقة.
- `public/screen.js` أعيد تنظيم طبقة العرض فيه مع الحفاظ على منطق Firestore والسيارات والصور والألوان والكاش والـ QR.

## منطقة صور السيارة
- لا يوجد Mask أو قوس يقص الصورة.
- الصورة الأصلية تعرض كاملة باستخدام `object-fit: contain`.
- خلف الصورة طبقة من نفس الصورة بتأثير Blur لملء المساحة بصريًا عند اختلاف أبعاد الصور.
- التصميم الموسمي يحيط بالـ Safe Area ولا يدخل فوق محتوى الصورة.
- مناسب للصور الخارجية، الداخلية، التفاصيل القريبة، والزوايا المختلفة.

## منطقة البيانات والمواصفات
- تكوين بصري واحد متصل بدل Cards/Blocks منفصلة.
- العنوان والسعر والألوان والمواصفات الرئيسية والفنية والمميزات جزء من نفس الـ Canvas.
- المواصفات الداخلية / الخارجية / الأمان: 14 عنصرًا في الصفحة — 7 يمين + 7 شمال.
- الصفحات الإضافية تستمر بالتنقل التلقائي واليدوي.

## التصميمات
- رمضان: كحلي وذهبي — بدون مسجد أو مبنى ديني.
- اليوم الوطني: أخضر وذهبي.
- يوم التأسيس: بني/ترابي بطابع نجدي هندسي.
- عيد الفطر: عاجي/ذهبي/تركواز — بدون مسجد أو مبنى ديني.
- عيد الأضحى: عنابي/ذهبي — بدون مسجد أو مبنى ديني.

## إعدادات هوية كل مناسبة من الداش بورد
- رفع/تغيير شعار المناسبة.
- التحكم في حجم الشعار.
- كتابة النص أسفل الشعار.
- التحكم في حجم خط النص أسفل الشعار.
- اليوم الوطني يدعم أيضًا تغيير الرقم (96، 97، ...).
- اختيار التصميم العام يطبق على كل الشاشات.

## الخط
- Tajawal هو الخط الأساسي في شاشة العرض والداشبورد.

## Firestore
تحتاج النسخة إلى صلاحية القراءة العامة والكتابة للإدمن على:
- `showroom_screens`
- `showroom_car_cache`
- `showroom_settings`
- `showroom_theme_settings`
- `showroom_screen_logs`
